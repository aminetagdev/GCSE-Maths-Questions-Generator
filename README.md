# GCSE Maths Worksheet Generator

A Python script I wrote to automate making GCSE maths practice sheets and worked answer keys for my tutoring sessions. Instead of writing questions out by hand every week, it generates randomised problems with clean integer answers and saves them as Markdown files.

## What it generates
- **Quadratic equations:** Factorisable quadratics built from integer roots so they always factorise cleanly.
- **Linear equations:** Equations with unknowns on both sides and whole-number solutions.
- **Pythagoras' theorem:** Right-angled triangle problems (finding both the hypotenuse and shorter sides) using scaled Pythagorean triples.
- **Mixed revision:** A random mix of all three topics.

Open as a .py file, run and you'll be greeted with some options.
